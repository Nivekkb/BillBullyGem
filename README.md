# BillBully

BillBully app.

## Setup

1) Install deps:
```
npm install
```

2) Run dev server:
```
npm run dev
```

3) Build for production:
```
npm run build
```

4) Start production server:
```
npm run start
```

## Firebase

The client config lives in `src/firebase/config.ts`. Update it to match your Firebase project,
or move the values to environment variables if you prefer a per-env setup.

To get started, take a look at `src/app/page.tsx`.
